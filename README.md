# 文件链接维护加载项（MyTools.xlam）

把大文件夹里的 Word 文件批量链接到 Excel 表格的 B 列，链接使用**相对路径**，整个文件夹可以原样复制给他人使用。

```
📁 大文件夹（整个文件夹拷贝给别人即可直接使用）
├── test.xlsx            表格（文件名固定，见常量 WB_NAME）
├── MyTools.xlam         本加载项
├── 1-cryaf3qa\cryaf3qa.docx
├── 2-9g12723w\9g12723w.docx
├── 3-dzmgcl36\dzmgcl36.docx
└── …
```

工程目录（开发用）：

```
src\FileLink.bas        VBA 模块：全部逻辑 + Ribbon 回调
src\customUI.xml        Ribbon 定义：「我的工具」选项卡
build\Build-AddIn.ps1   一键打包脚本 → dist\MyTools.xlam
dist\MyTools.xlam       可直接安装的加载项
源程序.bas               改造前的原始程序，仅供参考，未被修改
```

---

## 一、约定

| 项目 | 约定 |
|---|---|
| 根目录 | **读取 `test.xlsx` 所在的目录**（不使用绝对路径，复制整个文件夹即可换机器） |
| 表格文件名 | `test.xlsx`（常量 `WB_NAME`，与大文件夹同级） |
| A 列 | 序号，如 `1`、`2`……（也允许写完整文件夹名 `1-cryaf3qa`） |
| B 列 | 超链接，地址为相对路径 `1-cryaf3qa\cryaf3qa.docx`；单元格显示的是**不带后缀的文件名** `cryaf3qa`，点击即可打开 Word |
| 对应规则 | 文件夹 `序号-文件名`，内部同名 Word 文件；命名不规范时自动改名 |
| 留空规则 | 文件夹不存在、或文件夹里没有 Word 文件时，**B 列留空，不写任何占位文字** |

---

## 二、安装

```powershell
powershell -ExecutionPolicy Bypass -File build\Build-AddIn.ps1
```

生成 `dist\MyTools.xlam` 后把它**复制到大文件夹里**，Excel → 文件 → 选项 → 加载项 → 管理「Excel 加载项」→ 转到 → 浏览 → 选中它 → 勾选 **MyTools**。

> 打包前置条件：勾选「信任对 VBA 工程对象模型的访问」（文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置）。

安装后 Ribbon 出现 **「我的工具」→「文件链接」**，只有两个按钮：

| 按钮 | 作用 | 范围如何确定 |
|---|---|---|
| **更新所选行** | 清空所选行的 B 列并按现有文件重新生成链接 | 你在表里选中的行（单击某行任意单元格即代表该行，也可框选多行），自动裁剪到数据区内 |
| **末尾新增行链接** | 给表格底部新插入的行补链接 | 「最后一条已有链接」的下一行 → A 列最后一行；已有链接的行不动 |

典型用法：已处理到 100 行时新来了 5 个数据 → 把文件放进 `101-xxx`…`105-xxx` → 在表格末尾填好 101-105 的序号 → 点「末尾新增行链接」。

某个文件被替换、想单独刷新几行 → 选中那几行 → 点「更新所选行」。

## 三、行为细节

**相对路径**

链接的地址与悬浮提示是相对路径（如 `101-abc\abc.docx`），Excel 会相对表格所在目录解析，**和绝对路径一样可以直接点击打开**；因为不含盘符，文件夹被复制到别处或发给同事后依然有效。

**展示文字**

单元格里显示的一律是**文件名本身且不带扩展名**（`abc.docx` → `abc`，多段点的文件名如 `report.v2.final.docx` → `report.v2.final`），显示简洁统一；完整相对路径可在悬浮提示中看到。弹窗里列出的候选文件同样按此规则显示。地址本身不改，仍然是可点击的相对路径。

**留空，不写占位文字**
「批量创建空文件夹」这类场景下，序号存在但文件夹暂时没内容 → B 列保持空白。文件夹补齐内容后再跑一次即可自动补上链接。历史遗留的 `无docx文件` 等占位文字，在选中这些行点「更新所选行」后会被清成空白。

**文件夹自动改名**
命名始终对齐 `序号-文件名`：

- `4\simfour.docx` → `4-simfour`
- `5-old\simfive.docx`（文件被替换）→ `5-simfive`
- 已一致 → 不动；目标名被占用或文件正开着 → 放弃改名，该行留空（结束时计入「改名失败」）

**弹窗只发生在一种情况**
某个文件夹里有 **2 个以上 docx**：列出文件清单并提供「手动选择文件 / 跳过本行 / 中止本次」。否则全自动。

文件夹里的 xlsx、压缩包、子文件夹、Word 临时文件（`~$` 开头）一律忽略。

运行结束给出计数：生成链接、改名、跳过已有链接、文件夹不存在（留空）、无内容（留空）、待人工确认、改名失败、写链接失败。

## 四、可调常量（`src\FileLink.bas` 顶部）

```vba
Private Const WB_NAME          As String = "test.xlsx"  ' 表格文件名
Private Const EXT_TARGET       As String = "docx"       ' 关注的文件扩展名
Private Const COL_SEQ          As String = "A"          ' 序号列
Private Const COL_LINK         As String = "B"          ' 链接列
Private Const HEADER_ROWS      As Long = 1              ' 表头行数
Private Const AUTO_RENAME      As Boolean = True        ' 文件夹命名与文件名保持一致
Private Const SHOW_REPORT      As Boolean = True        ' 运行结束显示计数
```

改完后重新执行打包脚本，并在 Excel 里取消勾选再重新勾选 MyTools。

## 五、与早期版本的差异

| 项目 | 早期版本 | 当前版本 |
|---|---|---|
| 根目录 | 取活动工作簿所在目录 | 读取 `test.xlsx` 所在目录；未打开时自动打开加载项同目录下的同名表格 |
| B 列链接 | 绝对路径 | **相对路径**，可整体复制迁移 |
| 占位文字 | 写「无docx文件」「文件夹不存在」 | 一律**留空** |
| 功能 | 全量重建 / 增量更新 / 数字行范围输入 / C 列变更备注 | 仅保留「更新所选行」「末尾新增行链接」 |
| 输入控件 | 起始行、结束行输入框 | 全部移除（改为按选区、按末尾自动判断） |

## 六、排错

| 现象 | 处理 |
|---|---|
| 看不到「我的工具」选项卡 | 加载项未勾选/被禁用：文件 → 选项 → 加载项 → Excel 加载项 → 勾选 MyTools |
| 提示未找到 `test.xlsx` | 表格文件名必须是 `test.xlsx`，且与加载项位于同一层；或先手动打开它 |
| 提示“请先在表格中选中要更新的行” | 先单击目标行的任意单元格或框选多行，再点按钮 |
| 提示“没有检测到末尾新增行” | 表格最后一行已有链接；如需刷新，请改用「更新所选行」 |
| 点击按钮报“宏已被禁用” | 信任中心启用宏，或把该文件夹加入受信任位置 |
| 链接点了没反应 | 表格必须保存在大文件夹内；相对路径以表格所在目录为基准 |
| 改名失败 | Word 正打开着该文件，关闭后重新处理该行 |

> 正式使用前建议先复制一份文件夹试跑。
