一、方案变更说明

变更原因：经现场核实，原设备安装图仅为底部支撑——设备背部与侧面均无可利用的固定点。此前版本（HTR-SUP-R1）采用的"下部承重支架 + 上部拉结支架"四点固定方案不再成立：上部拉结无处生根。

约束条件（已与业主确认）：① 设备底部距装修完成地面净空 < 450 mm，无加设斜撑的空间；② 装修面板上开孔 尽量少；③ 设备底部有与原支架连接的 M6 螺纹孔（每侧 2 孔，间距 123 mm），倾覆力偶可由此传递。

新方案（本版）：取消上部拉结，改为纯悬臂底托式支架——每台设备由 2 根从混凝土墙直接悬挑的闭口方管（□50×50×3，304L）托底，方管顶面通过原底部 M6 螺纹孔与设备连接。倾覆力矩全部由悬臂根部锚栓群承担。

为什么悬臂主体改用方管、不能沿用 3 mm 折弯板：纯底部支撑下，地震水平力作用点距支撑面 400 mm，面内（平行墙）工况还需叠加两臂间的滚转力偶，根部弯矩达 116.9 N·m/支。若仍用 3 mm 折弯 U 形开口截面：组合应力约 86.7 MPa（利用率 85%），且摇摆频率约 19 Hz，落入楼层反应谱放大概率较大的频段，抗震裕度不足。改用闭口方管后：应力 17.9 MPa（利用率 18%），摇摆频率约 35 Hz（刚性区）。壁厚 3 mm 与原板材同规格，牌号仍为 304L；原支架的 3 mm 板材可改制为垫板与封板等配件。

三、方案布置与传力路径

每台设备 2 根悬臂方管（件1），根部焊接 100×180×8 底板，底板贴混凝土墙面、藏在装修面板之后，每板 4-M10×100 化学锚栓直接锚入结构墙。方管穿过面板上 110×200 的矩形孔伸出，顶面焊接 50×80×6 垫板并与设备底面齐平，用原底部螺纹孔连接——方管上下壁与垫板对钻 2-Ø7 通孔，M6×35 螺栓由下向上穿入设备底部螺纹孔（闭口方管内无法放置螺母，栓头与垫圈留在方管底面下方）。1#（离墙 130）仅方管长度不同，截面与锚固完全相同。

传力路径：竖向荷载（G、Fv）→ 方管受弯/受剪 → 根部底板 → 锚栓剪力与混凝土承压；水平地震（垂直墙面）→ 设备底部螺栓对传递倾覆力偶 → 方管弯矩 → 根部锚栓群上排受拉、下排承压；水平地震（平行墙面）→ 两臂（间距 610）形成竖向力偶抵抗滚转。设备自身不设置任何背部、侧面固定点，全部地震效应经底面单一平面传入支架。

4.2 悬臂方管内力与应力（2# 最不利）

截面：□50×50×3　A = 564 mm²　I = 208 492 mm⁴　W = 8 340 mm³
工况②包络：Mx = 375.4 N × 311.5 mm = 116.9 N·m；My = 103 N × 311.5 mm = 32.1 N·m
σ = (116.9 + 32.1)×10³ / 8 340 = 17.9 MPa ≤ 102 MPa　利用率 18%

1#（离墙 130）：Mx = 86.8 N·m，σ = 14.3 MPa，利用率 14%。两台共用同一截面，1# 富余更大。

4.3 设备底部 M6 连接螺栓（2-M6×35/侧，由下向上穿入）

工况①倾覆力偶：41.2 N·m / 臂 → 螺栓对竖向力 = 41.2×10³/123 = 335 N
受拉校核：335 N / (0.5×170 MPa × 20.1 mm² = 1 709 N) = 20%
叠加剪力 51.5 N/栓，组合利用率 ≈ 25% ✔

螺栓须为 304L 全螺纹杆，穿方管上下壁 Ø7 通孔后拧入设备底部螺纹孔 ≥20 mm，头部加平垫+弹垫防松（位于方管底面下方）。工况③的上拔力 32 N 亦由该螺栓承担（<2%）。

4.4 根部角焊缝（方管周边焊于底板，hf = 3）

两条立焊缝（有效截面）：Iw = 2×(0.707×3×50×25²) = 1.33×10⁵ mm⁴
σw = 116.9×10³×25 / 1.33×10⁵ = 22.0 MPa；τw = 375/(2×0.707×3×50) = 1.8 MPa　≤ 48 MPa ✔

4.5 底板与锚栓

底板 100×180×8，锚栓 4-M10 布置 60（水平）×140（竖向）
根部弯矩 → 锚栓群力偶 = 116.9/0.14 = 835 N → 上排每栓拉力 418 N，下排承压 835 N（板-混凝土面承压 σ ≈ 0.06 MPa）
每栓剪力 = √(375² + 103²)/4 ≈ 98 N
M10 化学锚栓（C25、埋深 90）：设计拉力 ≈ 5 300 N，剪力 ≈ 4 600 N
组合利用率 = 418/5300 + 98/4600 ≈ 11% ✔（撬力已按 8 mm 板、边距 20 mm 复核，计入后仍 <15%）

4.6 变形与刚度（摇摆频率）

静载竖向挠度 δ = 240×311.5³/(3EI) ≈ 0.06 mm
SSE 下根部转角 θ = 116.9×10³×311.5/(EI) = 8.7×10⁻⁴ rad → 设备顶部位移 ≈ 0.7 mm
摇摆频率 f = (1/2π)·√(2EI/L / (m·h²)) ≈ 35 Hz（> 33 Hz，刚性附件，Ω=2.0 包络成立）

4.7 抗震能力包络

按线弹性换算，本方案母材可承受约 102/17.9 = 5.7 倍设计地震（相当于等效静力约 1.7g），足以包络 117′ 标高刚性附件可能出现的零周期加速度放大；若实测楼层反应谱 ZPA 超过 1.7g，需按实际谱值重新复核。

八、施工要点

  1. 拆除：先设临时支撑托住设备再拆原 M6×70 膨胀螺栓；原锚栓很可能打在轻钢龙骨上，拆装修板孔位时注意龙骨回弹。
  2. 面板开孔：按支架中心位置在装修面板开 110×200 矩形孔（每支架 1 个，每台 2 个），孔边打磨去毛刺。
  3. 支架就位：底板（连同焊好的方管）平穿入面板孔、贴紧混凝土面；用水平仪校正方管顶面标高（= 设备底面标高）与离墙尺寸（210/130），临时点固。
  4. 锚栓施工：经面板孔用冲击钻对混凝土钻 4-Ø12×90 孔/板，逐孔吹洗（吹-刷-吹），注入化学锚栓药剂，固化期内严禁扰动。
  5. 紧固：M10 螺母按锚栓产品规定力矩紧固（一般 20~25 N·m），24 h 后复紧一遍。
  6. 设备安装：吊装设备落于两方管垫板上，对准底部螺纹孔，由下向上穿 2-M6×35/侧 拧紧（约 8 N·m，勿过力损伤设备螺纹孔）。
  7. 收尾：方管与面板孔间隙不打胶封闭（留 5 mm 观察缝）或按业主要求加盖装饰板。
  8. 记录：锚栓批号、固化时间、紧固力矩、离墙实测值填入竣工资料。
